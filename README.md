# Proyek Pemrograman Mobile
## Deskripsi
Aplikasi latihan untuk tugas kuliah

## Pengembang

## Status
Proyek awal perkuliahan.

## Tujuan Aplikasi
Aplikasi ini dikembangkan sebagai media pembelajaran praktikum pemrograman mobile menggunakan Flutter untuk memahami alur kerja Git, struktur antarmuka, dan manajemen state.

## Rencana Fitur
1. Halaman autentikasi dan profil pengguna.
2. Tampilan daftar modul dan ringkasan materi praktikum.
3. Fitur pelacakan progres tugas perkuliahan secara interaktif.

## Cara Menjalankan
Pastikan Flutter SDK dan Android Studio/JDK 17 sudah terkonfigurasi. Jalankan perintah:
```bash
flutter pub get
flutter run
